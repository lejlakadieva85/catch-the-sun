Сравните варианты застройки

Добавьте технико-экономические показатели вариантов. Критерии и веса настраиваются на следующем шаге.

Исходные данные

Вариант Общая площадь, м² Этажность Плотность, м²/га Инсоляция, ч Действия

Проверка данных перед расчётом

Пустая таблица → «Добавьте минимум 2 варианта для сравнения».

Ошибка в ячейке → подсветить поле и показать причину рядом.

Загрузка файла → показать прогресс, затем список строк с ошибками.

Данные сохраняются при переходе между шагами.

Настройте правила сравнения

Выберите критерии, направление предпочтения и метод оценки. Ниже показана предлагаемая настройка для обсуждения.

Метод оценки

TOPSIS: близость к идеальному варианту. AHP: отдельный ввод парных сравнений.
Парето: слои недоминируемых решений без взвешенной суммы. Формула V: исходная методика UrbanSketch.

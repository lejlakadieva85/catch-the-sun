# Поймать солнце — Калькулятор многокритериальной оценки вариантов застройки

Прототип настраиваемого веб-калькулятора для модуля М2 («Выбор») проектного практикума УрФУ (проект № Ц2.48). Позволяет сравнивать варианты жилой застройки по технико-экономическим показателям (ТЭП) и инсоляции с использованием методов многокритериального анализа.

## Основные возможности

1. **Шаг 01 · Ввод данных:** добавление и редактирование вариантов застройки (общая площадь, этажность, плотность, инсоляция), автоматическая проверка корректности заполнения перед расчётом.
2. **Шаг 02 · Критерии и метод:** выбор метода оценки (`TOPSIS`, `AHP / МАИ`, `Парето`, `Формула V`), настройка направления оптимизации («Больше — лучше» / «Меньше — лучше») и весов критериев с автоматической нормализацией до 100 %.
3. **Шаг 03 · Результаты:** расчёт итогового рейтинга вариантов, детальное объяснение вклада критериев для выбранного варианта и сводная таблица сопоставления методов.


## Как запустить проект локально

Для запуска требуется установленный [Node.js](https://nodejs.org) (версия 18 и выше).

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/lejlakadieva85/catch-the-sun.git
   cd catch-the-sun
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите локальный сервер для разработки:
   ```bash
   npm run dev
   ```
4. Откройте в браузере ссылку `http://localhost:5173/`.
